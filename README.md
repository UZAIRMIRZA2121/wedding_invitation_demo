# Rida  & Usman  — Royal Wedding Invitation (Next.js)

An ultra-modern, luxury digital wedding invitation built with **Next.js 14 (App Router)**, **TypeScript**, **Tailwind CSS**, and **Framer Motion**.

---

## ✨ Features & Modern Enhancements

1. **💌 Interactive 3D Royal Wax Seal Envelope:**
   - Realistic 3D folded envelope with a wax seal stamped with `"Z & N"`.
   - Clicking the seal or button initiates a celebration confetti burst and smooth 3D unfolding animation.

2. **📜 Multi-Page Smooth Animated Experience (Framer Motion):**
   - **Page 1 (Cover):** Monogram, Islamic Calligraphy & Bismillah, Grand Couple Typography (*Great Vibes* & *Cormorant Garamond*), royal borders, and date badges.
   - **Page 2 (Sacred Union):** Surah Ar-Rum quote with family blessings and couple story.
   - **Page 3 (Event Details & Live Countdown):** Real-time countdown timer (Days, Hours, Minutes, Seconds) to November 15, 2026, with an instant `.ics` calendar download button (*Add to My Calendar*).
   - **Page 4 (Surprise Scratch-to-Reveal Card):** Real HTML5 Canvas scratch-off card with shimmering gold foil. Guests can scratch with mouse or finger to uncover a personalized blessing accompanied by a confetti burst.
   - **Page 5 (Program Timeline):** Step-by-step wedding itinerary with gold milestone dots (Arrival, Baraat, Nikkah, Royal Feast, and Rukhsati).
   - **Page 6 (Venue & Navigation):** Styled venue card for *Victoria Marquee, Faisalabad* with one-click Google Maps opening, one-click copy address, and dress code tips.
   - **Page 7 (Interactive RSVP & Live Guestbook):** Full interactive RSVP form where guests select their attendance, input their party size, and leave heartfelt prayers that stream live on the on-page guestbook.
   - **Share & Replay:** One-click WhatsApp/URL sharing and instant replay controls.

3. **🌸 Floating Romantic Petals & Gold Dust Canvas:**
   - 60 FPS Canvas background with gentle drifting gold sparkles and floral petals.

4. **🎵 Ambient Music Synthesis (Web Audio API):**
   - Built-in soothing ambient melody with interactive Play/Mute toggle and animated audio waves.

5. **📱 Gestures & Accessibility:**
   - Supports mobile touch swipes (up/down), keyboard navigation (Arrow Up/Down, Page Up/Down), top progress bar, and bottom navigation pill dots.

---

## 🚀 Getting Started

### 1. Development Server
Run the local dev server:
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### 2. Production Build
```bash
npm run build
npm run start
```
